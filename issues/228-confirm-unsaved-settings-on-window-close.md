# ウィンドウ終了時にも未保存設定の保存確認を出す

## 問題

設定画面内の通常遷移では、未保存変更がある場合に保存確認ダイアログを出している。

しかしウィンドウの×ボタンや、複数起動時に既存プロセスを閉じる経路では、未保存変更の確認が出ない。

## 期待する挙動

設定画面で未保存変更がある状態でウィンドウを閉じようとした場合、既存の保存確認ダイアログを表示して、保存して閉じるか、保存せず閉じるか、閉じる操作をキャンセルできる。

複数起動で既存プロセスを閉じる場合も、未保存変更を失わない。

## 受け入れ条件

- [ ] 設定画面で未保存変更がある状態の×ボタンで保存確認ダイアログが出る。
- [ ] 保存して閉じる、保存せず閉じる、キャンセルの挙動が既存の保存確認ダイアログと揃う。
- [ ] 複数起動による既存終了要求でも未保存変更を失わない。
- [ ] 未保存変更がない場合は従来どおり閉じられる。
- [ ] frontend template/API検査とGo testが通る。
