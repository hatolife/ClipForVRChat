# UI上のすべてのボタンにマウスオーバー説明を追加する

## 問題

一部のボタンはラベルやアイコンだけでは、押すと何が起きるのか、対象範囲がどこまでなのか、取り消し可能なのかが分かりにくい。
特に設定、履歴、自動撮影、診断、外部連携、削除やリセット系の操作では、利用者が不安なまま押す可能性がある。

## 期待する挙動

UIに存在するすべてのボタンで、マウスオーバー時にそのボタンの機能が短く分かる説明を表示する。
説明はボタン名の単なる繰り返しではなく、実行される操作、対象、注意点が必要に応じて分かる内容にする。

## 受け入れ条件

- [ ] 通常画面、結果表示、履歴画面、設定画面、情報画面、自動撮影関連UIにあるすべてのボタンを棚卸しする。
- [ ] 各ボタンに `title` または既存UIパターンに沿った tooltip を追加する。
- [ ] アイコンのみのボタンは、視覚ラベルがなくてもマウスオーバーで機能が分かる。
- [ ] 削除、リセット、外部送信、ファイルを開く、設定保存など副作用のあるボタンは、対象範囲や結果が分かる説明にする。
- [ ] 無効状態のボタンでも、可能な範囲で「なぜ押せないか」または「何を満たすと押せるか」が分かる。
- [ ] キーボード操作やスクリーンリーダー向けに、必要に応じて `aria-label` などのアクセシビリティ属性も補う。
- [ ] Vue template literalを変更した場合は `node scripts/check-frontend-template-literals.mjs` と `node scripts/check-wails-api-surface.mjs` を実行する。
