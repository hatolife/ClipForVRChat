# 詳細設定画面でも保存/閉じるボタンを表示する

## 問題

自動撮影の詳細設定画面に入ると、設定画面上部の「保存」「閉じる」ボタンが表示されず、変更後に保存または設定画面を閉じる操作へ戻りにくい。

## 期待する挙動

自動撮影の詳細設定画面でも、通常の設定画面と同じように「保存」「閉じる」ボタンを表示する。

## 受け入れ条件

- 自動撮影の各詳細設定画面で「保存」「閉じる」ボタンが表示される。
- 詳細設定画面の「戻る」ボタンは従来通り詳細一覧へ戻る操作として残る。
- 保存中表示と保存完了表示が通常の設定画面と同じ挙動を保つ。
- Vue template literal検査とWails API surface検査が通る。
