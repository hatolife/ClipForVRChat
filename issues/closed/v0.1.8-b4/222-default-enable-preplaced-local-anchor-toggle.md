# フォールバックモード自動切替設定の解釈誤り

## 問題

#211で追加したローカルアンカー配置済みカメラのフォールバックモードについて、当時の実装では既定値や自動切替の扱いを誤って解釈していた。
ユーザーの意図は、フォールバックモード自体を既定ONにすることではなく、自動でフォールバックモードへ切り替えるかどうかを別設定にすることだった。さらに #235 の追加指示で、ON化制御とOFF化制御は別フラグに分ける。

## 期待する挙動

このチケットの当初解釈は誤りとして扱う。
#235で、自動フォールバックON化設定と自動フォールバックOFF化設定を追加し、どちらも既定OFFにする。自動切替OFFではユーザーが選んだフォールバックモードON/OFFを尊重する。

## 受け入れ条件

- #235で自動フォールバックON化設定が追加される。
- #235で自動フォールバックOFF化設定が追加される。
- #235で自動フォールバックON/OFF設定の既定値はOFFになる。
- #235でフォールバックモード自体の既定値はOFFになる。
- #235で自動切替OFF時はユーザー設定を尊重し、basis不足なら通常撮影失敗を正常動作として扱う。
