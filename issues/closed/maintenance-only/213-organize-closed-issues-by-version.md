# 完了済みissueを対応バージョンごとのフォルダに整理する

## 問題

完了済みissueが `issues/closed/` 直下に多数並んでおり、過去リリースごとの変更内容を追いにくい。
ユーザーから `issues/old` を対応バージョンごとのフォルダに整理したいという要望があるが、現在のリポジトリでは完了済みissueの保管場所は `issues/closed/` になっている。

## 期待する挙動

- 完了済みissueを対応バージョンごとのフォルダに分け、リリース単位で確認できる。
- `issues/closed/README.md` のリンクが移動後のファイルを正しく指す。
- 対応バージョンがリリースではないものも、調査のみ・整理のみ・未定などの分類で見失わない。

## 受け入れ条件

- [x] `issues/closed/` 配下の完了済みissue Markdownが対応バージョン別フォルダへ移動されている。
- [x] `issues/closed/README.md` のリンクが移動後パスへ更新されている。
- [x] `issues/README.md` と `AGENTS.md` の完了済みissue移動ルールが新しい配置と矛盾しない。
- [x] 移動後に壊れたMarkdownリンクがないことを確認する。
