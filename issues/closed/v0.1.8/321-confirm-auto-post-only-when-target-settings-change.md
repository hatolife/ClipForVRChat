# 設定保存時の自動処理投稿確認を対象設定変更時だけ表示する

## 指示

> 設定保存の度に下記が出る 下記が変更されたときだけ出したい
> ```
> 自動処理の投稿内容を確認してください
> 下記の自動処理は、監視フォルダに追加された画像をDiscordへ投稿します。保存前に監視フォルダと送信先を確認してください。
>
> VRChat写真自動処理
> 監視フォルダ: [REDACTED: local user path]
> Discord投稿: ON / 送信先: [REDACTED: discord webhook token]
> スクリーンショット自動処理
> 監視フォルダ: [REDACTED: local user path]
> Discord投稿: ON / 送信先: [REDACTED: discord webhook token]
> 送信先が未設定の場合は投稿に失敗します。広いフォルダを監視すると、意図しない画像も投稿対象になります。
> ```

## 文脈

設定保存時に、自動処理の監視フォルダとDiscord送信先の確認ダイアログが毎回表示されている。ユーザーは、表示されている自動処理項目の内容が変わった場合だけ確認したい。

## 解釈

保存前確認は安全上必要だが、未変更の自動投稿設定に対して毎回表示すると通常の設定保存を妨げる。前回保存済み設定から、監視フォルダ・送信先・Discord投稿ON/OFF・自動処理ON/OFFなど自動投稿の実効内容が変わった場合だけ表示する。

## 問題

自動処理がDiscord投稿ONで有効な状態だと、保存対象の変更有無に関係なく確認ダイアログが出る。

## 期待する挙動

自動処理の監視フォルダや送信先など、ダイアログに表示される投稿内容に関係する設定が変更された保存時だけ確認ダイアログを表示する。

## 受け入れ条件

- VRChat写真自動処理とスクリーンショット自動処理の確認は、対象の有効化、監視フォルダ、専用Webhook、通常投稿Webhook、Discord投稿ON/OFFが変更された場合に表示される。
- 無関係な設定だけを変更して保存した場合、自動処理投稿確認は表示されない。
- 自動撮影のDiscord投稿先未設定確認も、関連設定が変更された場合だけ表示される。
