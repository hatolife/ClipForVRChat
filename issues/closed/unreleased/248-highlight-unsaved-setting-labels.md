# 未保存変更の対象設定ラベルをハイライトする

## 指示

未保存変更 自動撮影 OSC
のような表記が出るがこの時その項目のラベルがハイライトされるようにしたいという指示が忘れられている気がする
もしくは実装されているがハイライトが動作していない？
もしくは実装されているがその項目がないとか？

## 文脈

以前の指示で、設定値に変更があって保存していない項目名をハイライトしたいという要望があった。現在は未保存変更チップとして `自動撮影 OSC` のような大分類名が表示されるが、設定画面内のどの行やラベルが対象なのか視覚的に分かりにくい。

## 解釈

未保存変更の表示に出ている項目と対応する設定行をハイライトする。大分類だけでなく、該当する個別設定行のラベル周辺も目立つようにし、現在開いているタブ内で変更箇所を探せる状態にする。対応する行がタブ外にある場合は、タブボタンも未保存状態として示す。

## 問題

- 未保存変更チップは出るが、画面内のどの設定行が変更されたか分かりにくい。
- `settingRowChangedClass` が一部行にしか付いていない。
- タブ外の変更は現在の画面から気づきにくい。

## 期待する挙動

- 未保存変更がある設定行はラベルを含めてハイライトされる。
- 未保存変更があるタブはタブボタン上でも分かる。
- `自動撮影 OSC` のようなチップが出る変更では、OSCタブ内の該当行がハイライトされる。

## 受け入れ条件

- [x] 未保存変更があるタブボタンにハイライトが付く。
- [x] 未保存変更がある設定行のラベルがハイライトされる。
- [x] OSC関連の変更時、OSCタブ内の該当行がハイライトされる。
- [x] 既存の保存確認ダイアログや変更検出ロジックを壊さない。
