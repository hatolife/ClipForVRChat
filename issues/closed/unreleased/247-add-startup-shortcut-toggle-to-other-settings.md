# その他タブにPC起動時自動起動トグルを追加する

## 指示

終わったらでいい

更新タブをその他に変更
 
その他タブにClipForVRChatをPC起動時に自動起動するための設定を行うトグルスイッチを追加したい
実装的にはstartupにショートカットを張るだけにしたい
OFFになったときちゃんと消すようにしたい
作成されるショートカット名はバージョンに寄らずClipForVRChatにしてほしい
つまりどのバージョンからでもショートカットを削除できるようにしてほしい
トグルスイッチをON/OFF切り替えられた時に常に削除作成を行うようにしたい
複数バージョン複数個所にexeがあってもトグルスイッチをON/OFF切り替えたexeにショートカットが張りなおされるイメージ

## 文脈

設定画面には現在 `更新` タブがあり、更新確認と更新通知の設定だけが置かれている。ユーザーはこのタブをより広い `その他` タブへ変更し、PC起動時にClipForVRChatを自動起動する設定を追加したい。設定ファイルの永続値ではなく、Windows Startup フォルダへ固定名ショートカットを作成・削除する運用を求めている。

## 解釈

タブ表示名を `更新` から `その他` に変え、既存の更新確認設定はそのタブ内に残す。新しいトグルは Startup フォルダの `ClipForVRChat.lnk` を対象にし、ON/OFF切り替え時は毎回まず同名ショートカットを削除する。ONの場合は現在実行中のexeを指すショートカットを作り直す。OFFの場合は削除だけを行う。これにより、別バージョンや別配置のexeからでも固定名ショートカットを消せ、ONにしたexeへ張り直せる。

## 問題

- 更新タブ名が、新しいその他設定を置く場所として狭い。
- PC起動時の自動起動をUIから設定できない。
- 複数バージョンや複数配置のexeがある場合でも、Startupショートカットを固定名で管理する必要がある。

## 期待する挙動

- 設定画面の `更新` タブが `その他` と表示される。
- その他タブに「PC起動時に自動起動」トグルが表示される。
- ONにすると Startup フォルダの `ClipForVRChat.lnk` が削除後、現在のexeを指す形で作成される。
- OFFにすると Startup フォルダの `ClipForVRChat.lnk` が削除される。
- どのバージョンのClipForVRChatから操作しても同じ固定名ショートカットを管理する。

## 受け入れ条件

- [x] 設定タブの表示名が `その他` になる。
- [x] その他タブにPC起動時自動起動トグルがある。
- [x] トグルON時、`ClipForVRChat.lnk` を削除してから現在exe向けに作成する。
- [x] トグルOFF時、`ClipForVRChat.lnk` を削除する。
- [x] ショートカット名にバージョンや配置パスを含めない。
- [x] Windows以外やショートカット操作に失敗した場合はUIでエラーが分かる。
