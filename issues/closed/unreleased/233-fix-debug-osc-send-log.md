# OSCデバッグ送信が送信ログに表示されない

## 問題

設定画面のOSCデバッグ送信で任意のOSCを送信しても、受信ログが多いと共有ログバッファから送信ログが押し出され、下部のOSC送信ログに送信内容が表示されない場合がある。

## 期待する挙動

OSC受信/転送ログとOSC送信ログを別バッファで保持し、受信ログが多い状態でもOSCデバッグ送信の送信内容が送信ログに残る。

## 受け入れ条件

- OSCデバッグ送信の成功時にOSC送信ログへ1件表示される。
- OSCデバッグ送信の失敗時にも、エラー状態としてOSC送信ログへ表示される。
- OSC受信/転送ログとOSC送信ログは別バッファで保持され、受信ログ増加で送信ログが消えない。
- 既存のOSC traceで送信ログが追加済みの場合は、同じ送信を二重表示しない。
- 関連するGoテストが通る。
