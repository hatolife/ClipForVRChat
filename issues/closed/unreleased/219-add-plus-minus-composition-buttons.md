# 構図設定の右下に＋/－ボタンを追加する

## 問題

構図の追加や削除がカード内の文字ボタン中心で、構図設定全体の操作として分かりにくい。

## 期待する挙動

構図設定の一番右下に、ラベルが `＋` と `－` の追加・削除ボタンを表示する。
`＋` は新しい構図を追加し、`－` は末尾の構図を削除する。

## 受け入れ条件

- 構図設定リストの右下に `＋` / `－` ボタンを表示する。
- `＋` で新しい構図を追加できる。
- `－` で末尾の構図を削除できる。
- 構図がない場合、`－` は無効になる。
- 既存のカード内削除ボタンは維持する。

## 対応内容

- 構図設定リストの右下に `＋` / `－` ボタンを追加した。
- `＋` は新しい `player_local` 構図を追加する既存処理に接続した。
- `－` は末尾の構図を削除し、構図がない場合は無効にした。
- 既存の構図カード内削除ボタンは維持した。
- 構図カード内の「現在Poseから追加」と「初期Poseへ戻す」を削除し、「現在Poseを保存」を「現在Poseを取得」、「このPoseへカメラ移動」を「この位置に移動」へ変更した。
