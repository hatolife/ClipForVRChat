# 未保存変更のある設定項目を行としてハイライトする

## 指示

```text
未保存変更の項目名が大分類だけで分かりにくい
についてそもそもの指示を無視している
項目をハイライトする指示を守ってない
```

## 文脈

#231では未保存変更がある項目名を設定画面上部にチップ表示した。#234ではチップの項目名を具体化した。しかしユーザーの指示は、変更された設定項目そのものをハイライトすることだった。

## 解釈

未保存変更のサマリー表示だけでは不十分。変更された設定項目の行、入力欄、または対応するUI要素に視覚的なハイライトを付け、画面上でどこが変更されたか分かるようにする。

## 問題

未保存変更がある項目を上部チップで表示するだけで、実際の設定項目がハイライトされていない。

## 期待する挙動

設定画面内で変更された項目の行や入力欄がハイライトされ、ユーザーが変更箇所を直接確認できる。

## 受け入れ条件

- 主要な設定行に未保存変更時のハイライト表示を追加する。
- 少なくともOSCホスト、OSC送信ポート、OSC受信ポート、フォールバック関連設定、構図設定でハイライトが効く。
- 既存の未保存変更チップ表示は補助情報として残してよい。
- frontend template/API整合チェックが通る。
