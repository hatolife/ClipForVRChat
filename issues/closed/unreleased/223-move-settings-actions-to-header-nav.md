# 保存/閉じるボタンを上部ナビ右へ移動する

## 問題

設定画面の「保存」「閉じる」ボタンが設定パネル内のタイトル行にあり、詳細設定画面やスクロール量によって操作位置が分かりにくい。

## 期待する挙動

設定画面を開いている間は、上部ヘッダーの「設定」「使い方」「情報」ボタンの右側に少し余白を空けて「保存」「閉じる」ボタンを表示する。

## 受け入れ条件

- 設定画面中、上部ナビの右側に「保存」「閉じる」ボタンが表示される。
- 設定パネル内タイトル行の「保存」「閉じる」ボタンは重複表示しない。
- 保存中表示と保存完了表示が従来通り機能する。
- Vue template literal検査とWails API surface検査が通る。
