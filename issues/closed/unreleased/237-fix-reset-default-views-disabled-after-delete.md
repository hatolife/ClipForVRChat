# 構図削除後に初期3構図へ戻すとグレーアウトする

## 指示

```text
構図設定で-ボタンで項目数減らしてその後初期3構図に戻すを押すとついかされるがグレーアウトする
```

## 文脈

構図設定には末尾の構図を削除する `-` ボタンと、初期3構図に戻すボタンがある。フォールバックモード中は構図PoseやZoomを使わないため、構図編集UIがグレーアウトされる。

## 解釈

`-` ボタンで構図数を減らした後に初期3構図へ戻すと、構図自体は追加されるが、追加された構図が未キャリブレーションまたは無効状態として扱われ、グレーアウト表示になる問題を修正する。

## 問題

構図削除後に初期3構図へ戻すと、初期構図が追加されるが操作対象として分かりにくいグレーアウト状態になる。

## 期待する挙動

初期3構図へ戻した直後は、通常の有効な初期構図として表示・操作できる。

## 受け入れ条件

- `-` ボタンで構図を減らした後に初期3構図へ戻しても、追加構図が不要にグレーアウトしない。
- 初期3構図のenabled/calibrated/coordinateSpace等が既定構図として正しく補正される。
- 関連テストまたはフロント検査が通る。
