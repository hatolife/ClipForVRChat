# OSC送信ログを分離し任意OSC送信欄を追加する

## 問題

OSCログが送信と受信で混在しており、受信確認と送信確認を分けて見づらい。

また、デバッグ目的で任意のOSCを送信するUIがない。

## 期待する挙動

OSC設定タブで、既存の受信ログ表示を維持しつつ、その下に同じ見た目の送信専用ログを表示する。

さらに下に1行入力欄と送信ボタンを置き、任意のOSCを現在設定のVRChat OSC送信先へ送れる。

## 受け入れ条件

- [x] 受信ログと送信ログが別々に表示される。
- [x] 送信ログは送信方向のOSCだけを表示する。
- [x] 入力欄と送信ボタンから任意OSCを送信できる。
- [x] 送信結果が送信ログと画面上の状態表示に反映される。
- [x] frontend template/API検査とGo testが通る。
