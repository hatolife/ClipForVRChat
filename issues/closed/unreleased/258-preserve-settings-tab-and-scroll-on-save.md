# 保存ボタンで設定タブとスクロール位置を移動しない

## 指示

> 終わったら 保存ボタンを押したとき設定画面の機能タブが表示される 表示画面を移動したくない　スクロール位置も変わらないようにしたい

## 文脈

設定画面の保存ボタンを押すと、現在開いている設定タブや詳細画面から「機能」タブへ戻ってしまう。長い設定画面では保存後にスクロール位置も変わり、編集中の場所を見失う。

## 解釈

保存完了後も、保存前に表示していた設定タブ、詳細画面、スクロール位置を維持する。設定画面を新しく開いた時の初期タブは従来通りでよい。

## 問題

- 保存時に設定画面の表示タブが「機能」へ戻る。
- 保存後にスクロール位置が変わる。

## 期待する挙動

- 保存ボタンを押しても、表示中の設定タブや詳細画面が変わらない。
- 保存ボタンを押しても、スクロール位置が変わらない。

## 受け入れ条件

- [x] 通常の保存で `settingsTab` が保存前と同じままになる。
- [x] 自動撮影詳細画面で保存しても詳細画面から戻らない。
- [x] 保存後にスクロール位置を復元する。
- [x] 関連チェックが通る。

- `node scripts/check-frontend-template-literals.mjs`
- `node scripts/check-wails-api-surface.mjs`
