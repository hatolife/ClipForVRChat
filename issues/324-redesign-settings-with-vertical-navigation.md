# 設定画面を縦ナビゲーションとカテゴリ別ペインへ再設計する

## 指示

> 設定画面を改善したい
> 現在設定数が多い上に結構混乱する
> 機能として大きなカテゴリ、縮小処理、投稿処理、撮影処理があり
> おまけ機能として、WinShiftSの処理、QRコード読み取り、その多機能がある
> 設定画面の横方向のタブをやめて、vscodeの設定画面のように左に縦に項目、右に項目の設定を出す感じにしたい

## 文脈

現行設定画面は上部の横タブに「機能」「処理」「Discord投稿」「自動撮影」「OSC」「その他」を並べている。設定項目の増加により、処理の目的とタブ名の対応が分かりにくく、横幅も使う。

## 解釈

- 設定画面を左側の縦ナビゲーションと右側の設定ペインに分ける。
- 主要カテゴリを「機能 ON/OFF」「縮小処理」「投稿処理」「撮影処理」として明示する。
- 技術設定と補助設定は「OSC」「その他」に分け、主要カテゴリと視覚的に区切る。
- 既存の設定値、保存、未保存警告、確認ダイアログ、自動撮影詳細画面の挙動は維持する。
- 狭い画面では縦ナビゲーションを上部へ移して操作可能にする。

## 問題

- 横タブではカテゴリ数と長いラベルが増えるほど見通しが悪くなる。
- 「処理」「Discord投稿」「自動撮影」では、それぞれ縮小・投稿・撮影という目的が即座に伝わりにくい。
- 設定の主機能と補助的な設定が同じ階層に並び、優先順位が分かりにくい。

## 期待する挙動

- 左にカテゴリ一覧、右に選択カテゴリの設定が表示される。
- 主要カテゴリと「OSC・その他」が見出しで区切られる。
- 選択中カテゴリと未保存変更のあるカテゴリが分かる。
- 自動撮影の詳細設定を開いても、左ナビゲーションから別カテゴリへ移動できる。
- 760px以下では1列表示になり、カテゴリ一覧が設定内容より先に表示される。

## 受け入れ条件

- [x] 横方向タブを左側の縦ナビゲーションへ変更する。
- [x] 「機能 ON/OFF」「縮小処理」「投稿処理」「撮影処理」「OSC」「その他」のラベルで表示する。
- [x] 主要カテゴリと詳細・その他カテゴリを視覚的に分ける。
- [x] active状態、未保存カテゴリ表示、キーボード操作用のtab semanticsを維持する。
- [x] 自動撮影詳細画面とレスポンシブ表示が崩れない。
