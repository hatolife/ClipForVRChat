# 保存せず終了した設定変更を一時変更として復元する

## 問題

強制終了や複数起動による既存終了などで、設定画面の未保存変更が失われる可能性がある。

## 期待する挙動

未保存変更がある場合、`%LOCALAPPDATA%\ClipForVRChat\single-instance` 配下に一時変更を保持する。

次回起動時に一時変更が残っている場合は、設定ファイルへ保存せず、画面上の一時状態として反映する。

## 受け入れ条件

- [ ] 未保存変更があるとき一時変更ファイルがsingle-instance配下へ保存される。
- [ ] 保存または保存せず破棄した場合、一時変更ファイルは削除される。
- [ ] 起動時に一時変更ファイルがあれば、設定画面の一時状態として反映される。
- [ ] 反映時に設定ファイルへ自動保存しない。
- [ ] Go testが通る。
