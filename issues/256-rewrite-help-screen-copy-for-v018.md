## 文面草案

### 使い方

ClipForVRChatは、VRChatで使う画像URLを作ったり、撮影した画像を保存・投稿したりするためのアプリです。

### 機能概要

1. 画像を処理する
   - 既定では、大きい画像を最大2048x2048に収まるよう縮小できます。
   - 画像ファイルをドラッグ&ドロップして処理できます。
   - クリップボードに入っている画像も処理できます。
   - 複数画像をまとめて処理できます。

2. 処理した画像を保存・投稿する
   - ローカルフォルダへ保存できます。
   - Discord Webhookへ投稿できます。
     - 投稿後の画像URLをコピーできます。
   - QRコードURL検出をONにすると、画像内のQRコードURLを結果画面やDiscord本文に含められます。

3. 自動で画像を処理する
   - VRChat写真フォルダを監視して、ゲーム内で撮影された新しい写真を自動で処理できます。
   - スクリーンショットフォルダを監視して、Windows+Shift+Sなどで保存された画像を自動で処理できます。

4. VRChatのカメラで自動撮影する
   - AvatarBeaconを使うと、アバター基準の構図を設定し、自動でカメラを移動させて撮影できます。
     - OSCでUser Cameraを操作して、設定した構図や間隔で撮影できます。
     - Stream Camera(Spout)の映像を取得して画像として保存できます。
   - フォールバックモードでは、VRChat内であらかじめ配置したローカルアンカーCameraを使って撮影できます。
     - AvatarBeaconを使えない場合でも撮影できます。
     - ClipForVRChatはカメラ移動を送信しません。
     - 構図ごとの位置、拡大率、表示対象などは使われず、VRChat内で配置済みのカメラ状態をそのまま使います。

5. 結果やログを確認する
   - 履歴画面で過去の処理結果を確認・整理できます。
     - 履歴画面からDiscordに投稿した画像を削除できます。
   - OSCタブで送受信OSCを確認できます。
   - 不具合報告用データを生成し、設定、履歴、ログをまとめて送れる形にできます。

### 1. 画像縮小

まずは、処理したい画像ファイルをこのウィンドウへドラッグ&ドロップします。スクリーンショットなど、クリップボードに入っている画像を使う場合は、「クリップボード画像を処理」ボタンから処理できます。複数の画像をまとめて処理することもできます。

既定では、大きい画像は最大2048x2048に収まるよう縮小されます。画像形式、JPEG品質、ファイル名のサフィックスなどは設定画面から変更できます。

### 2. 画像保存・投稿

処理した画像は、設定に応じてローカル保存、Discord投稿、URLコピーが行われます。Discordへ投稿する場合は、設定画面で投稿先チャンネルのWebhook URLを登録してください。Webhook URLの作り方は、使い方画面からDiscord公式ヘルプを開いて確認できます。

処理結果は結果画面に表示されます。画像URLがある結果ではURLをコピーできます。ローカル保存した結果では、保存先を開けます。1枚だけ処理した場合は、設定がONなら画像URLを自動でクリップボードへコピーします。

画像内のQRコードURLを使いたい場合は、QRコードURL検出をONにします。検出したURLは結果画面に表示され、Discordへ投稿する場合は本文にも含められます。

### 3. 自動画像処理

VRChatで撮った写真を毎回手でドロップしたくない場合は、自動処理を使います。VRChat写真フォルダを設定しておくと、ゲーム内で撮影された新しい写真を検出して自動で処理できます。

Windows+Shift+Sなどで保存したスクリーンショットを自動処理したい場合は、スクリーンショットフォルダの監視をONにします。Discord投稿、ローカル保存、URLコピーの動きは通常の画像処理と同じ設定に従います。

### 4. 自動撮影

より踏み込んで、VRChat内のカメラを使って定期的に撮影したい場合は、自動撮影を使います。自動撮影は、VRChatのUser CameraをOSCで操作し、設定した構図や間隔で撮影する機能です。v0.1.8ではStream Cameraの映像をSpout経由で取得する方式を中心にしています。単一exe版では必要なSpout helperを同梱しているため、通常は追加で配置する必要はありません。

アバター基準の構図で撮影するには、AvatarBeaconをアバターへ導入します。AvatarBeaconは、アバターの位置や向きをOSCでClipForVRChatへ送るためのアバターギミックです。ClipForVRChatはその情報を使って、正面、背面、斜めなどの構図をアバター基準で計算します。

AvatarBeaconを使えない場合は、フォールバックモードを使えます。フォールバックモードでは、VRChat内であらかじめ配置したローカルアンカーCameraを使って撮影します。ClipForVRChatはカメラ移動を送信しないため、構図ごとの位置、拡大率、表示対象などは使われません。

現在のVRChatでは、Camera UIを閉じるとCamera OSCが効かない不具合が報告されています。そのため、自動撮影を使うときはゲーム内でカメラを手動で起動しておく必要があります。将来VRChat側で解消された場合に備えて、カメラの自動起動・終了に関する設定は用意していますが、既定ではOFFです。

### 5. 結果・ログ確認

履歴画面では、これまで処理した画像の結果を確認できます。Discordへ投稿した画像、ローカル保存した画像、履歴だけに残っている画像を区別しながら、必要に応じて削除や整理ができます。履歴画面からDiscordに投稿した画像を削除することもできます。

OSCタブでは、VRChatから受信したOSCやClipForVRChatから送信したOSCを確認できます。他のOSCアプリも同時に使いたい場合は、VRChatから届いたOSCを別ポートへ転送できます。送受信ログは `logs/osc_send.jsonl` と `logs/osc_recieve.jsonl` に最新1000件だけ保存され、不具合報告用データにも含まれます。

不具合報告が必要なときは、情報画面から不具合報告用データを生成できます。生成される暗号化済みファイルを添付すると、設定、履歴、ログなどを確認しやすくなります。暗号化前の確認用zipも作られますが、添付するのはファイル名に「これを添付してください」と付いたgpgファイルです。
