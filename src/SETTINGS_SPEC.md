# ClipForVRChat 設定画面仕様

## 目的

設定画面は、通常ユーザーが `config.json` を直接編集せずに必要な動作を切り替えられるようにする画面です。

設定項目は、ユーザーが判断しやすい粒度でカテゴリ分けします。頻繁に触る可能性が低い詳細値は、概要行から開く詳細設定画面、または内部設定として扱います。

## 画面構成

- 見出し
  - 左側に `設定` を表示する。
  - 右側に `保存` と `閉じる` ボタンを表示する。
  - 自動撮影の詳細設定画面でも、同じ保存/閉じる操作を表示する。
  - 保存が成功した場合は `保存しました` を短く表示する。
- カテゴリタブ
  - 見出しの下に表示する。
  - 表示順は `機能`、`処理`、`自動撮影`、`OSC`、`Discord投稿`、`その他` とする。
  - タブはカテゴリ切り替え専用にする。
  - 選択中カテゴリの設定だけを表示する。
- 設定項目
  - 左側に設定名と説明を表示する。
  - 右側に入力欄、トグル、選択欄、ボタンなどの操作部品を表示する。
  - ON/OFF項目はトグルスイッチで表示する。
- 未保存変更
  - 未保存変更があるタブと項目を強調表示する。
  - 設定画面を離れる前、またはウィンドウを閉じる前に保存、破棄、キャンセルを選べる確認を表示する。
  - 単一起動の既存ウィンドウへ戻った場合も、保存前の下書きを復元できる。

## カテゴリと項目

### 機能

- VRChat写真自動処理
  - 種別: ON/OFF
  - 説明: VRChat上で撮影された写真フォルダを監視し、新しい画像を処理する。
- スクリーンショット自動処理
  - 種別: ON/OFF
  - 説明: WindowsのScreenshotsフォルダを監視し、新しい画像を処理する。
- QRコードURL検出
  - 種別: ON/OFF
  - 説明: 画像内のQRコードからURLを取得する。

### 自動撮影

自動撮影タブは概要行と詳細設定画面に分けます。

- AvatarBeacon受信状態
  - 種別: 状態表示 + 更新ボタン
  - 説明: `avatar_osc` basis の受信状態、最終受信時刻、position、yaw、エラーを表示する。
- フォールバックモード
  - 種別: ON/OFF + 詳細設定
  - 説明: ローカルアンカー配置済みCameraを使い、ClipForVRChatからCamera Poseを送らずに撮影する。
  - 自動ON/OFF: AvatarBeacon未受信時の自動ON、受信復帰時の自動OFFを個別に設定できる。どちらも既定OFF。
- 自動撮影スケジュール
  - 種別: ON/OFF + 詳細設定
  - 説明: 一定間隔で自動撮影する。
  - 項目: 撮影間隔、初回待機時間、開始時撮影、前回撮影中のスキップ、最大実行回数。
  - 既定: 開始時撮影はON、自動撮影スケジュール自体はOFF。
- 撮影と出力
  - 種別: 詳細設定
  - 項目: 撮影方式、Spout helper、Spout sender、自動選択、Stream取得timeout、開始待機、録画デバッグ、録画フレーム数、保存先、保存形式、ファイル名テンプレート、sidecar JSON、画像埋め込みメタデータ、Discord本文/メタデータへ含めるユーザー情報。
  - 既定: Stream方式、Spout sender自動選択、sidecar JSON ON、画像埋め込みメタデータ ON。
- Camera状態復元
  - 種別: 詳細設定
  - 説明: 撮影前に受信したUser Camera OSC値を優先し、不足分は設定した戻し先で復元する。
  - 項目: Mode、Streaming、SmoothMovement、Pose、Zoom、Exposure、FocalDistance、Aperture、表示対象mask類など。
- 構図
  - 種別: 一覧 + 編集
  - 説明: `world` または `player_local` の構図を管理する。
  - 操作: 現在Poseを保存、構図追加、既定へ戻す、Camera移動、テスト撮影。
  - 既定構図: 正面、背後、斜め。いずれも `player_local`。
- 自動撮影用Webhook URL
  - 種別: Discord投稿タブのパスワード入力
  - 説明: 自動撮影だけ別のDiscordチャンネルへ投稿したい場合に使う。空の場合は通常投稿用Webhook URLを使う。

### OSC

- OSCホスト
  - 種別: テキスト入力
  - 既定: `127.0.0.1`
- OSC送信ポート
  - 種別: 数値入力
  - 説明: 外部アプリからVRChatへ送るUDPポート。
  - 既定: `9000`
- OSC受信ポート
  - 種別: 数値入力
  - 説明: VRChatから外部アプリへ届くUDPポート。ClipForVRChatはここを代表してlistenする。
  - 既定: `9001`
- カメラOSCリセット
  - 種別: ボタン
  - 説明: VRChat User CameraのOSC操作状態を戻す。
- プレイヤー基準の取得元
  - 種別: 選択
  - 値: `avatar_osc`, `manual`
  - 既定: `avatar_osc`
- AvatarBeacon受信状態
  - 種別: 状態表示 + 更新ボタン
  - 説明: 自動撮影タブと同じ受信状態を確認する。
- OSC転送
  - 種別: ON/OFF + 転送先一覧
  - 説明: VRChatから受信したOSC packetを、他アプリ用の別ポートへUDP転送する。
  - 転送モード: `all` または `unhandled_only`。
  - 自分自身の受信ポートと同じ転送先は起動時に除外する。
- OSC受信ログ
  - 種別: 一時表示 + 正規表現フィルタ + コピー
  - 説明: 受信とforwardのログを表示する。
  - 補足: 終了時や診断パッケージ作成時には `logs/osc_recieve.jsonl` に保存する。
- OSC送信ログ
  - 種別: 一時表示 + コピー
  - 説明: ClipForVRChatからVRChatへ送信したOSCだけを表示する。
  - 補足: 終了時や診断パッケージ作成時には `logs/osc_send.jsonl` に保存する。
- OSCデバッグ送信
  - 種別: テキスト入力 + 送信ボタン
  - 説明: 現在のVRChat OSC送信先へ任意のOSCを送る。

### 処理

- ローカル保存
  - 種別: ON/OFF
  - 説明: 処理した画像をローカルに保存する。
- 出力先フォルダ
  - 種別: フォルダパス入力 + 選択ボタン
  - 説明: ローカル保存時の保存先。
- ファイル名サフィックス
  - 種別: テキスト入力
  - 説明: ローカル保存時のファイル名末尾に付ける文字。
- 出力形式
  - 種別: 選択
  - 値: `PNG`, `JPG`
  - 説明: 保存または投稿に使う画像形式。
- JPEG品質
  - 種別: 数値入力
  - 説明: JPG出力時の画質。

### その他

- PC起動時に自動起動
  - 種別: ON/OFF
  - 説明: Windows Startupフォルダに現在のexeへのショートカットを作成または削除する。
  - 補足: Windows以外では未対応状態を表示する。
- 更新確認
  - 種別: ON/OFF
  - 説明: 起動時にGitHub Releasesを確認し、新しいバージョンがあるか調べる。
- 更新通知
  - 種別: ON/OFF
  - 説明: 新しいバージョンが見つかったとき、画面上部に通知を表示する。

### Discord投稿

- Discord投稿
  - 種別: ON/OFF
  - 説明: 処理した画像をDiscord Webhookへ投稿する。
- 投稿URLの自動コピー
  - 種別: ON/OFF
  - 説明: Discordに投稿したURLをクリップボードに保存する。
- 通常投稿用Webhook URL
  - 種別: パスワード入力
  - 説明: 通常のDiscord投稿先。空の時は投稿できない。
- VRChat写真用Webhook URL
  - 種別: パスワード入力
  - 説明: VRChat写真自動処理だけ別のDiscordチャンネルへ投稿したい場合に使う。空の場合は通常投稿用Webhook URLを使う。
  - 補足: 空欄で通常投稿用Webhook URLが設定済みの場合は、そのURLへフォールバックすることを入力欄付近に表示する。
- スクリーンショット用Webhook URL
  - 種別: パスワード入力
  - 説明: スクリーンショット自動処理だけ別のDiscordチャンネルへ投稿したい場合に使う。空の場合は通常投稿用Webhook URLを使う。
  - 補足: 空欄で通常投稿用Webhook URLが設定済みの場合は、そのURLへフォールバックすることを入力欄付近に表示する。
- 自動撮影用Webhook URL
  - 種別: パスワード入力
  - 説明: 自動撮影だけ別のDiscordチャンネルへ投稿したい場合に使う。空の場合は通常投稿用Webhook URLを使う。
  - 補足: 空欄で通常投稿用Webhook URLが設定済みの場合は、そのURLへフォールバックすることを入力欄付近に表示する。
- Webhook作成案内
  - 種別: リンクボタン
  - 説明: Discord公式のWebhook作成案内を開く。

## 画面に出さない設定

- 最大入力サイズ
  - 通常ユーザーが頻繁に調整する値ではないため、設定画面には表示しない。
  - 内部設定値としては維持する。
- UI表示
  - 通常利用では変更頻度が低いため、設定画面には表示しない。
  - 内部設定値としては維持する。
- 自動撮影の複数カメラ同時撮影
  - 現行実装は順次撮影が主導線のため、通常UIでは同時撮影設定を主導線にしない。

## 依存関係と無効化

- Discord投稿がOFFの場合
  - 投稿URLの自動コピーをグレーアウトし、編集不可にする。
  - Discord投稿カテゴリの入力項目をグレーアウトし、編集不可にする。
  - VRChat写真自動処理とスクリーンショット自動処理はグレーアウトしない。縮小、QRコードURL検出、ローカル保存はDiscord投稿なしでも実行できる。
- VRChat写真自動処理がOFFの場合
  - VRChat写真用Webhook URLをグレーアウトし、編集不可にする。
- スクリーンショット自動処理がOFFの場合
  - スクリーンショット用Webhook URLをグレーアウトし、編集不可にする。
- 自動撮影のDiscord投稿がOFFの場合
  - 自動撮影用Webhook URLをグレーアウトし、編集不可にする。
- ローカル保存がOFFの場合
  - 出力先フォルダをグレーアウトし、編集不可にする。
  - ファイル名サフィックスをグレーアウトし、編集不可にする。
  - 出力形式をグレーアウトし、編集不可にする。
- ローカル保存がOFF、または出力形式がPNGの場合
  - JPEG品質をグレーアウトし、編集不可にする。
- 更新確認がOFFの場合
  - 更新通知をグレーアウトし、編集不可にする。
- 自動撮影スケジュールがOFFの場合
  - スケジュール詳細設定ボタンを無効化する。
- Stream方式以外の場合
  - Spout helper、sender、録画デバッグなどStream専用項目を無効化する。
- フォールバックモード中
  - `player_local` 構図のCamera移動は送信しない。

## 更新通知

更新確認がONの場合、起動時にGitHub Releasesの最新Releaseを確認します。

新しいバージョンがある場合は、ヘッダー下に更新通知を表示します。

更新通知には以下を表示します。

- 新しいバージョン番号
- GitHub Releasesを開くボタン
- BOOTHを開くボタン
- 通知を閉じる×ボタン

更新通知の×ボタンを押した場合、その起動中は通知を再表示しません。

更新確認がOFFの場合、起動時にGitHub Releasesの確認を行いません。

更新通知がOFFの場合、新しいバージョンが見つかっても画面上部の通知を表示しません。

## Discord投稿警告

Discord投稿がONで通常投稿用Webhook URLが空欄の場合、ヘッダー下にバナー形式の警告を表示します。

警告は設定保存後に画面を戻っても表示し、`設定する` ボタンからDiscord投稿タブを開けるようにします。

同じ条件では、通常投稿用Webhook URLの入力欄をオレンジ系の注意表示にします。

Discord投稿がOFFの場合、通常投稿用Webhook URLが空欄でも警告を表示しません。

## 自動処理の保存前確認

VRChat写真自動処理、スクリーンショット自動処理、自動撮影でDiscord投稿が有効な場合、専用Webhook URLと通常投稿用Webhook URLのどちらも空欄なら保存前確認ダイアログを表示します。

通常投稿用Webhook URLが設定済みの場合、専用Webhook URLが空欄でも通常投稿用Webhook URLへフォールバックするため、この確認ダイアログは表示しません。
