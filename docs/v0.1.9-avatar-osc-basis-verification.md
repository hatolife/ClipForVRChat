# v0.1.9 avatar_osc basis 実機確認手順

## 仕様前提

`avatar_osc` basis は、専用アバターギミックから VRChat OSC Avatar Parameters を受信して使う。
標準OSCだけでは動かない。デフォルトの原点は head/avatar 基準であり、player root 基準ではない。

## 専用アバターの準備

- VRChatで、専用ギミックを入れたアバターを使う。
- まずは `CFVRC/` prefix で確認し、必要なら `ATG/*` 互換も切り替えて試す。
- 受信対象の prefix は、実装側の status 表示と一致させる。

## 実機確認手順

1. VRChat側でOSCを有効にする。
2. 専用アバターを装着し、自動撮影タブを開く。
3. `player_local` の basis source を `avatar_osc` に切り替える。
4. `avatar_osc 受信状態` に受信中表示が出ることを確認する。
5. 最終受信時刻が更新されることを確認する。
6. position が移動に追従し、yaw が回転に追従することを確認する。
7. 一時的に別アバターへ切り替え、未受信または鮮度切れで止まることを確認する。
8. `manual` basis に戻しても、既存の手動基準Poseの挙動が壊れていないことを確認する。

## 撮影確認項目

- 正面、背後、斜めの `player_local` 構図で、移動後も相対構図が大きく崩れない。
- `avatar_osc` の受信状態、最終受信、position/yaw、エラー表示が UI から読める。
- 標準OSCだけの状態では、`avatar_osc` basis が使えないことが分かる。
- 受信停止時に、古い basis を使って撮影しない。
- Stream 方式と Photo 方式の両方で、basis の扱いが同じである。

## 失敗時に提出するもの

- `config.json`
- `logs/YYYY-MM-DD.log`
- 撮影画像と同名の `.json`
- 受信状態が分かる画面キャプチャ
- 使った prefix と parameter 配線のメモ
